🔹 ตัวอย่างที่ 3.5 (กรณีลู่เข้า / Convergence)

x₁ - 0.25x₂ - 0.25x₃ = 50
-0.25x₁ + x₂ - 0.25x₄ = 50
-0.25x₁ + x₃ - 0.25x₄ = 25
-0.25x₂ - 0.25x₃ + x₄ = 25
